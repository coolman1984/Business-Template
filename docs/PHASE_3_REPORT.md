# 📦 تقرير المرحلة الثالثة — أول دورة عمل كاملة: المخزون

## ما الذي بُني؟
| الجزء | ماذا يفعل |
|---|---|
| الأصناف | كود نصي (٠٠١٢ لا يتحول إلى ١٢) لا يتكرر في الشركة، واسم ووحدة؛ الوحدة لا تتغير بعد استخدام الصنف، والإيقاف بدل الحذف |
| المخازن | كل مخزن تابع لفرع، فصلاحيات الفرع تسري عليه تلقائيًا |
| المستندات | استلام وصرف ورصيد افتتاحي: تُحفظ مسودة أولًا ولا تغير الرصيد، ثم يرحّلها صاحب صلاحية الاعتماد فيأخذ رقمه عند الترحيل |
| فصل المهام | أمين المخزن يجهّز فقط، ومدير الفرع يرحّل ويعكس |
| دفتر الحركات | كل ترحيل يكتب حركة لكل صنف؛ الحركات لا تُعدَّل ولا تُحذف حتى من مالك قاعدة البيانات |
| الرصيد | ناتج من الحركات فقط، ولا ينزل تحت الصفر، وقاعدة البيانات ترفض أي تغيير له بدون حركة مصاحبة |
| التصحيح | المستند المُرحّل لا يُعدَّل؛ يُعكس بمستند مقابل مرة واحدة، ويبقى الأصل كما هو في السجل |
| تقرير الأرصدة | كل رصيد وبجانبه مجموع حركاته وعلامة «مطابق»، ومع كل صنف كشف حركة بالرصيد بعد كل حركة |
| الاستيراد | إكسل حديث أو CSV: معاينة كل صف مع سبب الخطأ بالعربي، والملف يُقبل كاملًا أو يُرفض، والتأكيد ينشئ مسودة تنتظر الاعتماد |
| الشاشات | المخزون: الأرصدة، المستندات، الاستيراد، الأصناف والمخازن — والأزرار حسب الصلاحية |

## اختبارات الخروج من الخطة (كلها ناجحة)
| الشرط | الدليل |
|---|---|
| عميل ينفذ دورة كاملة | في متصفح حقيقي: إضافة أصناف ومخزن ← استيراد رصيد افتتاحي ← ترحيله ← صرف مرفوض لأنه أكبر من الرصيد ← صرف صحيح ← عكسه ← كشف الحركة |
| مستخدمان لا يأخذان آخر قطعة مرتين | اثنان يرحّلان صرف آخر قطعة في نفس اللحظة ← واحد ينجح والثاني يُرفض؛ وستة يطلبون ٣ قطع ← ٣ ينجحون بالضبط والرصيد صفر |
| الحركات تطابق التقرير والسجل والاستيراد | كل رصيد يساوي مجموع حركاته، وكل حركة لها حدث ترحيل في سجل المراجعة، وأرصدة الملف المستورد تظهر كما هي بعد الترحيل |
| الرصيد الافتتاحي بحركة موثقة | يدخل كمستند «رصيد افتتاحي» مرتبط بملف الاستيراد، لا بتعديل رصيد مباشر |

**الأرقام:** ١٢١ اختبارًا ناجحًا (كانت ٩٨)، منها ٢٣ للمخزون.
**كسر متعمد:** شلت قفل الرصيد من الكود، فوقع اختبار «ستة يطلبون ثلاث قطع» فورًا.

## حماية الاستيراد من التكرار (٣ طبقات)
1. **بصمة الملف:** نفس الملف بالضبط في نفس المخزن يحتاج تأكيدًا صريحًا.
2. **مفتاح العمل:** صنف له حركة أو رصيد افتتاحي منتظر في نفس المخزن يُرفض، حتى لو اتغير اسم الملف أو اتحفظ من جديد.
3. **إعادة الفحص عند التأكيد:** لو البيانات تغيرت بعد المعاينة، يُرفض التأكيد ويُطلب رفع الملف من جديد.

والمعادلات في إكسل لا تُنفَّذ ولا تُقبل، وملفات الماكرو والصيغ القديمة مرفوضة، وفيه حدود للحجم والصفوف ضد الملفات الضارة.

## قرارات
- **قارئ إكسل مكتوب داخل المشروع** بدل مكتبة جديدة: يقرأ أول ورقة فقط بحدود حجم صارمة، وبدون أي تنفيذ.
- **الأصناف داخل محرك المخزون مؤقتًا.** الخطة تجعل الكتالوج محركًا مستقلًا، وسنفصله لما تحتاجه وصفة ثانية كالمبيعات.
- **الحجز غير مبني:** الخطة تقول «عند الحاجة»، ولا توجد حاجة بعد في هذه الدورة.

## حدود معلنة
- لا يوجد نقل بين مخزنين، ولا حجز، ولا دفعات أو أرقام مسلسلة، ولا تكلفة أو تسعير.
- الشاشات بالعربي فقط؛ الخطة تطلب الإنجليزية أيضًا.
- الاستيراد للأرصدة الافتتاحية فقط، ولملفات حتى ٥ ميجا و٢٠ ألف صف؛ الملفات الضخمة تحتاج مسار عمل خلفي.
- أمين المخزن يستطيع ترحيل مستند أعدّه بنفسه لو أُعطي صلاحية الاعتماد؛ منع ذلك («من أعدّ لا يعتمد») غير مبني.

## التالي: المرحلة الرابعة
الوصفة الثانية (مركز صيانة أو طلبات خدمات) على نفس النواة، ومولد ينشئ عميلًا من تعريف دون نسخ الكود.
