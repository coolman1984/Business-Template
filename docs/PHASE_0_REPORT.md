# 🧪 تقرير المرحلة صفر — إثبات الأساس

**القرارات المحسومة:** أول نشاط مخازن وطلبات لشركة صغيرة · المحاسبة الكاملة والمرتبات مؤجلة · التشغيل الأول على جهاز داخل الشركة.

## ما الذي بُني؟
| الجزء | ماذا يفعل |
|---|---|
| عزل الشركات في القاعدة | كل جدول تابع لشركة لا يظهر ولا يقبل الكتابة إلا لشركة الجلسة؛ بلا سياق = لا شيء |
| حسابان منفصلان للقاعدة | حساب المالك للترحيلات فقط، وحساب التشغيل لا يملك الجداول ولا يتجاوز العزل |
| بوابة أوامر واحدة | كل تغيير يمر بها: معاملة واحدة + صلاحية + سجل مراجعة + منع تكرار |
| صلاحيات | منع افتراضي، المنع الصريح يغلب، وكل منح حزمة كاملة (عملية + نطاق) لا تُخلط |
| سجل مراجعة | إضافة فقط؛ لا تعديل ولا حذف حتى من حساب المالك |
| ترقيم مستندات | متسلسل بلا فجوات لكل كيان قانوني ونوع وسنة |
| أول مورد أعمال | طلب تشغيل مرتبط بفرع: إنشاء، تعديل بنسخة، إرسال |
| تشغيل محلي | نفس الخادم والقاعدة على جهاز الشركة (ملف تشغيل حاويات أو مباشرة) |

## اختبارات الخروج (كلها ناجحة)
| شرط الخطة | الدليل |
|---|---|
| تبديل معرف شركة يُرفض | طلب في فرع شركة أخرى، أو معرف شركة في الطلب، أو تعديل سجل شركة أخرى بمعرفه ← مرفوض ولا أثر |
| الكتابة والسجل في معاملة واحدة | انهيار بعد الكتابة، فشل حفظ السجل، أو أمر نسي السجل ← لا طلب ولا سجل ولا رقم مستهلك |
| إعادة الطلب بلا تكرار | نفس الطلب مرتين أو ثلاثًا في نفس اللحظة ← طلب واحد |
| سحب صلاحية أثناء جلسة مفتوحة | الطلب التالي مباشرة يُرفض |
| تعارض تعديلين | التعديل بنسخة قديمة يُرفض بوضوح |

**اختبار الاختبارات:** كسرنا الحماية عمدًا خمس مرات (إيقاف العزل، تسريب السياق، تجاهل المنع، تخطي الصلاحية، السماح بكتابة بلا سجل) وفي كل مرة فشلت اختبارات مناسبة.

## حدود معلنة
- الهوية الحالية رموز دخول مؤقتة للتجربة؛ تُستبدل بمكتبة هوية معتمدة في المرحلة الأولى.
- لا أدوار جاهزة بعد (المنح على العضوية مباشرة)، ولا سقف تفويض للمديرين.
- ملف تشغيل الحاويات مكتوب لكن لم يُجرب داخل حاوية في بيئة التطوير؛ التشغيل المباشر جُرّب بنجاح.
- لا واجهة مستخدم بعد؛ التجربة عبر واجهة برمجية.

## التالي: المرحلة الأولى
أدوار ونطاقات، مكتبة هوية حقيقية وجلسات، شاشة صلاحيات مبسطة، وفحص آلي يمنع أي مسار كتابة لا يمر ببوابة الأوامر.
